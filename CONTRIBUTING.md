# Contribuer à ODACEA

**ODACEA n'accepte pas de contributions externes.** Les pull requests ne sont pas
fusionnées : le projet est développé et maintenu par son seul auteur.

## Ce qui est bienvenu

- **Bugs** : ouvrez une [issue](../../issues) « Rapport de bug » avec le contexte
  (OS, modèle LLM, taille du vrac) et les étapes pour reproduire.
- **Fonctionnalités** : ouvrez une issue « Demande de fonctionnalité » en expliquant
  le besoin métier.
- **Questions** : par issue également.

N'incluez aucune donnée sensible (chemins réels, noms de fichiers d'un fonds réel,
contenu de `.env`). Anonymisez vos exemples.

## Forker

Vous êtes libre de forker ODACEA selon les termes de la licence (voir [LICENSE](LICENSE)).
